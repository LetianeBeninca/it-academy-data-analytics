# Sprint 08.01 · Data visualization in Python

Connects to the Sprint 04 MySQL database, loads the tables with pandas and builds visualizations of one, two and three variables, a pairplot, a correlation heatmap, a jointplot and a violin plot, each with its interpretation.

- `sprint08_01_visualization.ipynb`: the notebook.

To run it you need the local MySQL database `db_sp04_transaction` (see [Sprint 04](../sprint-04-database-design)). The notebook asks for the MySQL password when it runs.
