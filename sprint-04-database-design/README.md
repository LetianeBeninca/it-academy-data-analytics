# Sprint 04 · Database design from CSV files

Design and creation of a database with a star schema from CSV files: dimension tables, a fact table, data loading, and queries over them (users with many transactions, average amount per IBAN, a card-status table).

- `sprint04_database_design.sql`: the script, including the data-loading steps.
- `sprint04_report.pdf`: the delivered report.

The CSV files come from the bootcamp and are not included. This database (`db_sp04_transaction`) is the one used in Sprint 08.01.
