# IT Academy · Data Analytics Bootcamp

Coursework from the **Data Analytics Bootcamp** (IT Academy, Barcelona Activa, 2025): relational databases and SQL, Power BI, Python and MongoDB. Each sprint is a short project on a business scenario, delivered with a report.

## Sprints

| Sprint | Topic | Tools | Folder |
|---|---|---|---|
| 02 | Relational databases and introduction to SQL | MySQL | [`sprint-02-sql-queries`](sprint-02-sql-queries) |
| 03 | Table manipulation: DDL/DML, indexes and views | MySQL | [`sprint-03-table-management`](sprint-03-table-management) |
| 04 | Database creation from CSV files (star schema) | MySQL | [`sprint-04-database-design`](sprint-04-database-design) |
| 05 | Introduction to data analysis with Power BI and KPIs | Power BI, DAX | [`sprint-05-power-bi-intro`](sprint-05-power-bi-intro) |
| 06 | Sales-pattern dashboards (B2B) | Power BI | [`sprint-06-power-bi-sales-patterns`](sprint-06-power-bi-sales-patterns) |
| 07 | Data structures and control flow | Python | [`sprint-07-python-data-structures`](sprint-07-python-data-structures) |
| 08.01 | Data visualization in Python | Python, pandas, matplotlib, seaborn, MySQL | [`sprint-08-01-python-visualization`](sprint-08-01-python-visualization) |
| 08.02 | Data visualization in Power BI | Power BI | [`sprint-08-02-power-bi-visualization`](sprint-08-02-power-bi-visualization) |
| 09 | Queries with MongoDB | MongoDB Compass | [`sprint-09-mongodb`](sprint-09-mongodb) |

Sprint 01 was the installation of the tools and has no deliverable. The final project (Sprint 10) is published in its own repository: [building-energy-ml-shap](https://github.com/LetianeBeninca/building-energy-ml-shap).

## Notes

- **Language:** the bootcamp was taught in Spanish, so exercise statements, SQL comments and notebook text are in Spanish.
- **Data:** the datasets are synthetic and provided by the bootcamp (companies, transactions, users and credit-card fields are fictional). The original CSV files are not included in this repository.
- **Sprint 08.01** connects to a local MySQL database built in Sprint 04 (`db_sp04_transaction`). It asks for the MySQL password when run; no credentials are stored in the code.
- The solutions are my own work. The exercise statements and datasets come from the bootcamp.
