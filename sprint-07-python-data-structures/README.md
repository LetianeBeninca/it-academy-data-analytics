Functions written for client requests, in three levels: a BMI calculator, a temperature converter, a word counter (also reading text files), a dictionary inverter (with and without duplicate values) and a type converter for mixed lists.

- `sprint07_data_structures.ipynb`: the notebook, with an explanation of each function.
- `sprint07_report.pdf`: the delivered report.
